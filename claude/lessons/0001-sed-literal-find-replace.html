Lesson 1 · sed

sed's s///: find-and-replace, literally

Tied to the mission: batch-renaming files and cleaning up text from the IncX3 work without touching each one by hand.

You've got a folder of downloaded assembly files, all named things like plasmid_pEC14.fasta, plasmid_pIncX-SVH.fasta, plasmid_pOLA52.fasta — and you want the plasmid_ prefix gone from every single one. Renaming forty files by hand is exactly the kind of task that should never take more than one line.

What sed actually does

sed stands for stream editor. It reads text one line at a time and applies an editing command to each line. The command you'll use almost constantly is s (substitute): 

sed 's/PATTERN/REPLACEMENT/FLAGS'

Read it as: on this line, find PATTERN, replace it with REPLACEMENT. For now, PATTERN is just literal text — no special characters yet. A literal string is already a perfectly valid pattern; the regex metacharacters (., *, [...], and friends) that make patterns more powerful are next lesson's problem, not this one's.

Two flags you need on day one
  • No flag → only the first match on each line is replaced.
  • g → every match on each line is replaced.

plasmid_pEC14.fasta only has one plasmid_, so it doesn't matter here — but it will matter later today.

Primary source — read this properly, not just this lesson

The Grymoire: Sed — An Introduction and Tutorial by Bruce Barnett. Widely considered the best plain-English sed tutorial online. Read at least the section on the s command before the next session.

Bioinformatics-flavoured alternative, if you'd rather see genomics examples straight away: Data Carpentry: Introduction to the Command Line for Genomics.

Try it: strip the prefix

Type a sed command into the box below and hit Run. Get the output to match what's described, then move on.

Goal: remove the plasmid_ prefix from every filename below.

Once that command does what you want, the actual renaming is one small step further — pipe each filename through the same sed command inside a loop: 

for f in plasmid_*.fasta; do
  mv "$f" "$(echo "$f" | sed 's/plasmid_//')"
done

This is exactly why literal sed substitution is worth learning on its own, before any regex metacharacters: most of your day-to-day renaming needs nothing fancier than this.

Now try the g flag

A FASTA header downloaded straight off ATB might look like this, underscores and all: 

>SAMN12345678_Escherichia_coli_IncX3_plasmid

You want every underscore turned into a space — not just the first one.

Goal: replace every underscore with a space.

Habit worth building now
Run your sed command without -i first and read the output before you trust it near real files. Only add -i (edit the file in place) once you've confirmed the command does exactly what you expect — there's no undo. Details in the sed cheat sheet.
