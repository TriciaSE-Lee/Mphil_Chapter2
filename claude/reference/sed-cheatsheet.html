sed cheat sheet

Grows as new lessons introduce new sed features. Currently covers: Lesson 1 (literal find-and-replace).

The one command that matters most: s

sed 's/PATTERN/REPLACEMENT/FLAGS' file.txt

Reads the input line by line. On each line, if PATTERN matches, replace it with REPLACEMENT. Nothing is written back to the file unless you tell it to (-i, below) — by default the result just prints to your terminal.

Delimiter

/ is the conventional delimiter, but any character right after s works. Useful when your pattern itself contains / (e.g. file paths):

sed 's/plasmid_//'        # delimiter is /
sed 's#/data/raw#/data/clean#'   # delimiter is # instead, since the pattern has slashes

Flags

FlagEffect
gReplace every match on the line, not just the first.
i or ICase-insensitive match.
(none)Replace only the first match on each line.

Command-line options

OptionEffect
-iEdit the file in place instead of printing to stdout. No undo — see warning below.
-i.bakEdit in place, but first save the original as file.bak. Cheap insurance.
-EExtended regex mode. Not needed for literal find-and-replace, but this workspace uses it consistently once regex metacharacters show up, so +/?/() don't need backslashes.
Habit
Run the command without -i first and read the output. Only add -i once you've confirmed it does what you expect. On macOS, -i requires an argument even if empty: sed -i '' 's/.../.../ ' file — on Linux, sed -i 's/.../.../ ' file works with no argument.

Renaming files with sed + a loop

sed edits text, not filenames directly — but combined with a bash loop, it drives batch renames:

for f in plasmid_*.fasta; do
  mv "$f" "$(echo "$f" | sed 's/plasmid_//')"
done
